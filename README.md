# SISTEMA ZION: La Bóveda Digital Soberana

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)

**ZION** es una bóveda digital descentralizada y un kit de supervivencia diseñado para la privacidad extrema y operaciones tácticas. Funciona como un **Monolito Híbrido**, ofreciendo un ecosistema de seguridad completo contenido en archivos HTML únicos y portátiles, con almacenamiento integrado en redes descentralizadas (Arweave/IPFS).

## 🛡️ Pilares Centrales
- **Huella Cero (Zero-Footprint):** Sin servidores, sin cookies, sin rastreo. Funciona totalmente en el navegador.
- **Protocolo de Pánico (NUKE):** Lógica de destrucción de datos y trituración de memoria instantánea.
- **Interruptor de Hombre Muerto:** Autodestrucción automatizada basada en la inactividad del usuario.
- **Esteganografía Arka:** Capacidad de ocultar sistemas enteros y datos sensibles dentro de imágenes inocentes.

## 📦 Componentes del Sistema
Zion se distribuye en tres versiones especializadas:
1. **ZION Web (La Bóveda):** El centro soberano completo para cifrado y gestión de datos.
2. **ZION Core (La Impresora):** Un nodo de construcción usado para generar kits de supervivencia localizados.
3. **ZION Lite (El Cartucho):** Archivos de documentos ultra-portátiles localizados en más de 24 idiomas.

## 🚀 Guía de Inicio
1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/sist3ma/zion.git
   ```
2. **Instalar dependencias (para construcción):**
   ```bash
   cd WEB_APP
   npm install
   ```
3. **Generar versiones:**
   ```bash
   node build_zion_core.js     # Generar ZION Core
   node build_zion_optimized.js # Generar archivos ZION Lite localizados
   ```
