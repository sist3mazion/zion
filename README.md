# ZION SYSTEM: The Sovereign Digital Vault

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)

**ZION** is a decentralized, resilient digital vault and survival kit designed for extreme privacy and tactical operations. It operates as a **Hybrid Monolith**, providing a full security ecosystem contained within single, portable HTML files.

## 🛡️ Core Pillars
- **Zero-Footprint:** No servers, no cookies, no tracking. Operates entirely in the browser.
- **Panic Protocol (NUKE):** Instant memory shredding and data destruction logic.
- **Dead Man Switch:** Automated self-destruction based on user inactivity.
- **Arka Steganography:** Hide entire systems and sensitive data inside innocent images.

## 📦 System Components
Zion is distributed in three specialized versions:
1. **ZION Web (The Vault):** The full-featured sovereign hub for encryption and data management.
2. **ZION Core (The Printer):** A builder node used to generate localized survival kits.
3. **ZION Lite (The Cartridge):** Single-purpose, ultra-portable document files localized in 24+ languages.

## 🚀 Getting Started
1. **Clone the repository:**
   ```bash
   git clone https://github.com/[YOUR-USERNAME]/[YOUR-REPO-NAME].git
   ```
2. **Install Dependencies (for building):**
   ```bash
   cd WEB_APP
   npm install
   ```
3. **Generate Builds:**
   ```bash
   node build_zion_core.js     # Generate ZION Core
   node build_zion_optimized.js # Generate localized ZION Lite files
   ```

## 🌍 Ideal Operational Environment
Zion is most effective when used on:
- **Air-gapped devices** for maximum isolation.
- **Tor Browser or LibreWolf** for enhanced privacy.
- **Decentralized networks** (Arweave/IPFS) for censorship resistance.
