## [EN] English Description

**ZION** is a decentralized, resilient digital vault and survival kit designed for extreme privacy and tactical operations. It operates as a **Hybrid Monolith**, providing a full security ecosystem contained within single, portable HTML files, with integrated storage on decentralized networks (Arweave/IPFS).

### 🛡️ Core Pillars
- **Zero-Footprint:** No servers, no cookies, no tracking. Operates entirely in the browser.
- **Panic Protocol (NUKE):** Instant memory shredding and data destruction logic.
- **Dead Man Switch:** Automated self-destruction based on user inactivity.
- **Arka Steganography:** Hide entire systems and sensitive data inside innocent images.

### 📦 System Components
1. **ZION Web (The Vault):** The full-featured sovereign hub for encryption and data management.
2. **ZION Core (The Printer):** A builder node used to generate localized survival kits.
3. **ZION Lite (The Cartridge):** Single-purpose, ultra-portable document files localized in 24+ languages.

### 🚀 Getting Started
```bash
git clone https://github.com/sist3mazion/zion.git
cd WEB_APP
npm install
node build_zion_core.js     # Generate ZION Core
node build_zion_optimized.js # Generate ZION Lite files
```

## [ES] Descripción en Español

**ZION** es una bóveda digital descentralizada y un kit de supervivencia diseñado para la privacidad extrema y operaciones tácticas. Funciona como un **Monolito Híbrido**, ofreciendo un ecosistema de seguridad completo contenido en archivos HTML únicos y portátiles, con almacenamiento integrado en redes descentralizadas (Arweave/IPFS).

### 🛡️ Pilares Centrales
- **Huella Cero (Zero-Footprint):** Sin servidores, sin cookies, sin rastreo. Funciona totalmente en el navegador.
- **Protocolo de Pánico (NUKE):** Lógica de destrucción de datos y trituración de memoria instantánea.
- **Interruptor de Hombre Muerto:** Autodestrucción automatizada basada en la inactividad del usuario.
- **Esteganografía Arka:** Capacidad de ocultar sistemas enteros y datos sensibles dentro de imágenes inocentes.

### 📦 Componentes del Sistema
1. **ZION Web (La Bóveda):** El centro soberano completo para cifrado y gestión de datos.
2. **ZION Core (La Impresora):** Un nodo de construcción usado para generar kits de supervivencia localizados.
3. **ZION Lite (El Cartucho):** Archivos de documentos ultra-portátiles localizados en más de 24 idiomas.

### 🚀 Guía de Inicio
```bash
git clone https://github.com/sist3mazion/zion.git
cd WEB_APP
npm install
node build_zion_core.js     # Generar ZION Core
node build_zion_optimized.js # Generar archivos ZION Lite
```
